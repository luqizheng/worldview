# ADR 模板

新建决策记录时复制本模板为 `ADR-NNNN-短标题.md`（NNNN 自 0001 起按序递增），
并在本目录维护。格式参考仓库根 `docs/adr/`（域模型决策记录）。

```markdown
# ADR-NNNN：<标题>

- 状态：Proposed | Accepted | Superseded by ADR-MMMM
- 日期：YYYY-MM-DD
- 决策人：<用户 / agent 提案>

## 背景

为什么需要这个决策；当前约束与相关已冻结决策（含仓库根 docs/adr 的冲突检查结论）。

## 决策

选择什么。逐条列出，可执行、可验证。

## 理由

为什么选它；考虑过的替代方案与不选的原因。

## 影响

对架构边界、跨平台要求、后续任务清单的影响；需要同步更新的文档。

## 验证

如何确认决策被正确落实（构建、测试、评审点）。
```

## 约定

- 一份 ADR 只记录一个决策；变更决策时新增 ADR 并将旧 ADR 标记为 Superseded，不修改历史结论。
- 与仓库根 `docs/adr/ADR-001~005`（已冻结）冲突时，必须先提新 ADR 交用户裁决。
- 状态为 Proposed 的 ADR 不得作为实现依据。
