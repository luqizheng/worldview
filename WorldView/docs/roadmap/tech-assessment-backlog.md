# 后续技术选型任务清单

工程初始化阶段**只建立清单，不做实现**。每项评估按以下流程进行：
调研 → 提案（含候选对比与推荐）→ 用户裁决 → ADR 落档 → 才允许引入依赖或编码。

约束：任何一项未冻结前，不得因其他任务方便而提前引入对应领域的大型依赖。

| # | 任务 | 关键问题 | 状态 |
| --- | --- | --- | --- |
| 1 | 地图 2D 渲染技术选型 | Avalonia 内 Skia 画布 / 自定义渲染层 / 性能指标（区域重绘、大图层） | 待评估 |
| 2 | 地图 3D 渲染技术选型 | Vulkan/Metal/OpenGL 封装与 Avalonia 集成方式、双平台一致性 | 待评估 |
| 3 | 几何计算引擎选型 | 多边形布尔运算、拓扑、精度；与渲染层的数据边界 | 待评估 |
| 4 | 地理空间数据引擎选型 | 矢量数据模型、坐标系处理、导入导出 | 待评估 |
| 5 | 空间索引选型 | R-Tree/网格；与渲染拾取、范围查询的衔接 | 待评估 |
| 6 | 本地存储与项目文件格式设计 | 单文件 vs 目录、增量保存、与 ADR-001~005 历史模型的配合 | 待评估 |
| 7 | Map Domain Services 设计 | 命令执行、历史状态引擎（P2-01-D01）的服务层落位 | 待设计 |
| 8 | AI Assistant 架构设计 | 模型接入方式、上下文注入、人机确认边界 | 待设计 |
| 9 | Task Planning & Execution Engine 设计 | 计划表示、执行调度、失败恢复 | 待设计 |

存储（6）与 Domain Services（7）次之；3D（2）与 AI 相关（8/9）在 2D 基线稳定后启动。
