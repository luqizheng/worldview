按依赖关系排序。每阶段给出：目标 / 具体任务 / 影响范围 / 前置条件 / 测试要求 / 人工验收标准。

- **具体任务**：
  1. 按 PR34 生命周期文档 §5 在 Windows / macOS 执行人工验收（重复打开只保留一个窗口；关闭成功首页恢复；关闭失败窗口保留可重试；关闭主窗口正常退出）。
  2. 合并 PR #34（不 squash 破坏其文档提交结构，按仓库现行惯例）。
  3. 决策项：确认放弃 master 注释中"启动面保留（多项目并存 V1 语义）"（`StartWindow.axaml.cs` L31 master），以 PR34 的"隐藏/恢复单工作区窗口"为准——本审计建议采纳 PR34 语义，理由：它消除了 DuplicateOpen 分叉窗口这一整类问题，且无历史用户依赖旧语义。
- **影响范围**：仅合并既有 PR，无新代码。
- **前置条件**：PR #34 CI 通过；人工验收通过。
- **测试要求**：PR34 自带测试（`ProjectSessionCloseTests` 216 行、`ProjectWorkspaceViewModelCloseTests` 117 行、`StartViewModelTests` +105 行）在 CI 绿。
- **人工验收标准**：上表 4 项场景双平台通过。

## 阶段 1：低成本修正（P1 文案类 + P2 快赢项）

**目标**：清除假数据与误导性 UI，工作量以小时计。

- **具体任务**：
  1. UI-03：删除 `ProjectWindow.axaml` 硬编码"世界地图"副标题。
  2. UI-06：右栏更名"已打开的地图会话"，文案去除编辑承诺；"关闭项目"降为普通按钮（或仅保留菜单项），移出 primary 位。
  3. UI-04（子集）：窗口 `Title` 拼接项目显示名；头部展示包路径（绑定 `Session.CanonicalPackagePath`，提供复制）；删除未绑定的 `SessionId` 属性。
  4. UI-11：删除项目页"LOCAL WORKSPACE"面板。
  5. UI-07：移除启动面侧栏"地图与场景"静态项。
  6. UI-12：`LoadMapsAsync` 调用改用 PR34 观察模式。
- **影响范围**：`WorldView.Desktop` 两个窗口 XAML + 两个 VM 属性；无 Application/Domain 变更。
- **前置条件**：阶段 0 完成。
- **测试要求**：既有 VM 测试全绿；受影响属性若有测试引用同步更新。
- **人工验收标准**：项目页无任何硬编码业务名词（grep 验证）；"关闭项目"非 primary；标题栏可区分不同项目；双平台布局无回归。

## 阶段 2：地图工作区窗口（WP-UI-04 建议范围）

**目标**：补全"打开地图 → 进入工作区"路径的 UI 终点（P1 UI-02、UI-05、UI-08、UI-10），为未来 Map Editor 提供宿主壳。

- **具体任务**：
  1. 新增 `MapWorkspaceWindow` + `MapWorkspaceViewModel`：持有 `MapWorkspaceSession`；标题显示地图名（打开前经 `IMapQueryService.GetMapAsync` 取 `DisplayName` 传入，或扩展 `MapSummary`）。
  2. 项目页交互改为：地图列表双击或"打开地图工作区"按钮 → 打开工作区窗口；项目页不再维护 `Workspaces` 镜像集合（UI-10），改为 `ProjectSession` 暴露工作区变更事件或由窗口管理器直接管理窗口集合。
  3. 工作区窗口内容区为占位（项目上下文信息 + "编辑能力随 ME 系列落地"提示），不实现绘制。
  4. 窗口关闭 = `Session.CloseWorkspaceAsync(workspaceId)`；项目关闭时全部工作区窗口随 `ProjectClosed` 级联关闭。
  5. UI-05：失败状态区分样式；地图列表失败加"重试"。
  6. UI-08：地图列表空状态引导（复用 PR34 最近项目空态模式）。
  7. 关闭确认语义预留：工作区窗口 `Closing` 拦截点先建立（当前恒放行），脏数据检查随编辑能力接入。
- **影响范围**：`WorldView.Desktop`（新窗口/新 VM/工厂注册）；`ProjectSession` 增加变更事件（Application 层小改）；组合根工厂扩展。
- **前置条件**：阶段 0、1 完成；`WorkspaceContextResolver` 正常（已具备）；每会话窗口的内存开销评估（当前单机单用户，可不做上限）。
- **测试要求**：
  - Application：工作区变更事件触发/解订阅/项目关闭级联（新增 Session 测试）。
  - Desktop VM：`MapWorkspaceViewModel` 关闭路径、显示名获取失败降级（新增测试）。
  - 沿用"不写无头窗口假测试"决策，窗口编排列入人工清单（UI-13 评估 headless 可测部分）。
- **人工验收标准**：
  1. 双击地图打开窗口，标题含地图名（非 GUID）。
  2. 同一地图开两个会话，两窗口独立，关其一不影响另一与项目会话。
  3. 项目"关闭项目"（菜单/标题栏）时所有工作区窗口关闭、首页恢复。
  4. 打开失败（构造非法上下文）有可见错误与重试。
  5. Windows/macOS 双平台窗口焦点/激活行为正常。
