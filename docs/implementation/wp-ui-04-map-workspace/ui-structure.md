# WP-UI-04A：MapWorkspaceWindow 第一版 UI 结构

视觉基调：专业、克制，适合桌面创作软件；沿用现有视觉资源
（`CardBrush` / `surface-card` / `subtle-panel` / `eyebrow` / `section-title` 等，
见 `ProjectWindow.axaml` L14-42 的既有用法）。Windows/macOS 同一 XAML，产品体验一致。

## 1. 窗口规格

| 项 | 值 |
| --- | --- |
| 尺寸 | `Width=1080 Height=720 MinWidth=760 MinHeight=520` |
| 标题 | `{项目名} — {地图名} — World View`（可读名称，**禁止 GUID**；见 G1/R1） |
| 数量约束 | 每张地图至多一个实例（窗口注册表保证） |
| 关闭入口 | 标题栏关闭按钮 + 菜单"文件 → 关闭工作区"（同一命令） |

## 2. 布局骨架

```
┌────────────────────────────────────────────────────────────┐
│ Row 0 (Auto) 顶栏：地图身份 + 状态徽章 + 文件菜单            │
├────────────────────────────────────────────────────────────┤
│ Row 1 (*)                                                  │
│  ┌──────────┐  ┌────────────────────────────────────────┐  │
│  │ 左栏(240) │  │ 中央区 (*)：Editor 宿主占位            │  │
│  │ 地图信息   │  │  - 空状态 / 加载中 / 错误态（互斥）    │  │
│  │ 卡片      │  │  - 未来：IMapWorkspaceEditor 内容      │  │
│  └──────────┘  └────────────────────────────────────────┘  │
├────────────────────────────────────────────────────────────┤
│ Row 2 (Auto) 底部状态栏：一条状态/诊断文本                  │
└────────────────────────────────────────────────────────────┘
```

对应 XAML 结构（04C 实现）：`Grid RowDefinitions="Auto,*,Auto"`；
中央区为 `ContentControl x:Name="EditorHost"`（**宿主占位**，本阶段内容为状态面板）。

## 3. 顶栏（Row 0）

- 左：eyebrow `MAP WORKSPACE` + 大字号地图名 + 小字号所属项目名（两行，主次分明）。
- 右：生命周期状态徽章（`Ready` / `Closing` / `关闭失败` / `Closed`，绑定 VM 状态）、
  `文件` 菜单（仅两项：`关闭工作区`；`关闭项目` 不放这里——项目关闭入口只在项目窗口）。

## 4. 左栏信息卡片（真实数据，无虚构）

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| 地图名 | `Session.MapName`（04B R1 新增；来自打开时的 `MapSummary.DisplayName`） | 无身份服务/查询失败时打开流程本就不会成功，故不存在"无名称"态 |
| 所属项目 | `Session.ProjectSession.ProjectDisplayName` | 复用既有投影 |
| 历史 Branch | `Session.Context.BranchId`（04C 先显示"默认历史"文案；BranchId 为 null 时显示"默认历史"，非空时显示"分支 {短 ID}"——**分支可读名依赖 Core Domain 查询，属 OQ-5**） | 不虚构名称 |
| 历史时间 | `Session.Context.CanonicalHistoricalTime`（typed 规范文本，既有计算属性） | |
| 项目路径 | `Session.ProjectSession.CanonicalPackagePath` | 补 WP-UI-03 发现的"包路径不可见"缺口 |

## 5. 中央区三态（互斥，由 VM 状态驱动）

| 态 | 触发 | 内容 |
| --- | --- | --- |
| 空状态 | `Ready` 且无 Editor（本阶段常态） | 图标（▦ 占位符，与项目窗口一致）+ "地图工作区已就绪。地图编辑器将在后续版本接入。" + 历史时间提示行。**不渲染任何虚构地图数据** |
| 加载中 | 未来 `Opening`（本阶段预留样式，不进入） | 不确定进度条 + "正在加载地图资源…" |
| 错误态 | 关闭失败重试期间 / 未来 Editor 加载失败 | 错误图标 + 诊断文本 + "重试关闭"按钮（绑定同一关闭命令） |

## 6. 底部状态栏（Row 2）

单行 `TextBlock`（`TextWrapping="Wrap"`），绑定 `StatusText`：
打开成功、上下文切换、关闭进行中、关闭失败诊断（复用 `CloseFailureDiagnostic`）、
已关闭。与 ProjectWindow 底栏样式一致（`ProjectWindow.axaml` L132-138）。

## 7. 交互清单

| 交互 | 行为 |
| --- | --- |
| 标题栏 X / 菜单"关闭工作区" | 走关闭命令（Session 成功释放才允许窗口销毁；失败保留可重试） |
| 关闭失败后再次关闭 | 幂等重试（`_closeInProgress` 防重入 + Session 状态机幂等） |
| 重复打开同图（在项目窗口再次点击） | 不新建窗口：已有地图窗口 `Activate()` 前置 |
| 项目窗口里"关闭所选工作区"（既有列表入口，04C 保留） | 同一关闭路径；对应地图窗口收到关闭结果后自毁 |
| 关闭项目 | 所有地图窗口被动跟随关闭（成功）或保留（该工作区失败时），见 `window-management.md` §4 |
| 窗口失焦/最小化 | 无特殊处理；激活语义见 `window-management.md` §2-Q6 |

## 8. 禁止项核对

- ❌ 虚构地图数据（空状态只写事实文案；历史时间来自 typed 权威解析）。
- ❌ 虚构编辑工具 / 无功能工具栏按钮（本阶段没有工具栏）。
- ❌ GUID 代替可读名称（标题、信息卡全部用显示名；MapId 不上 UI）。
- ❌ 过早引入复杂面板（无图层/属性/大纲面板——留给 Editor 工作包）。
- ❌ 关闭项目入口放进地图窗口（项目生命周期入口唯一，在项目窗口）。
