# 二进制格式规格 v0.1

> 本文是 World View **大网格二进制分块格式**的唯一真源：文件头、字节序、版本、块索引、坐标映射与校验。
> 它是 [总体设计 §2](../AGENTS.md) 原则 3「YAML 为主格式 + 大网格二进制例外」的**实现契约**：**索引与语义在 YAML，数值在二进制，声明可校验**。
> 字段语义以 [数据模型规格_v0.1.md](数据模型规格_v0.1.md) 为准（§3.5 `chunked`）；目录位置以 [存储与目录规范_v0.1.md](存储与目录规范_v0.1.md) §5.2 为准。

---

## 0. 定位与边界

| 允许 | 禁止 |
|---|---|
| 承载**定长数值数组**（地形类型、高度、通行成本等） | 承载任何**语义配置**（图例、单位、引用、名称） |
| 作为大网格的**一等源格式**（与 YAML 并列，受版本管理） | 作为元数据 / 矢量 / 对象数据的存储 |
| 被 YAML 索引显式声明后读取 | 隐式存在、无索引、无校验 |

- **不发明语义**：一个 `.bin` 里的字节，脱离 YAML 索引无法解释。图例（dtype 常量代表哪种地形）、单位、默认值一律在 YAML。
- **可重建性**：`.bin` 是**源**而非缓存；但由 YAML + 规则可完整解释其含义；损坏时可由校验器定位到块坐标并重建。
- **v0.1 口径**：本文定义**格式契约**。读写实现随 M1（工程骨架）落地，属实现层，不改变本契约。

## 1. 适用对象

| 数据模型字段 | 典型 dtype | 说明 |
|---|---|---|
| `terrain_data`（§3.2/§3.5） | `u8` | 地形类型枚举序号（见 §3.3 图例） |
| `height_data`（§3.3/§3.5） | `i16` / `u16` / `f32` | 高度值；范围大时用 `f32` |

- 仅当 `terrain_data.encoding == chunked`（或 `height_data.encoding == chunked`）时适用。
- **一张地图的一个数据数组 = 一个块目录**（`chunk_dir`），目录内一块一文件。

## 2. 坐标系统与块映射

网格坐标（整数格，见 [数据模型规格 §2.10](数据模型规格_v0.1.md)）到块坐标的映射：

```
cx = floor(x / chunk_size)          # 块列
cy = floor(y / chunk_size)          # 块行
lx = x - cx * chunk_size            # 块内列
ly = y - cy * chunk_size            # 块内行
index = ly * cell_w + lx            # 行优先线性下标（payload 内）
```

- `chunk_size` 默认 `64`（可配置），来自 YAML `chunk_size`。
- 地图为 `grid.width × grid.height` 格，块总数为 `ceil(width/chunk_size) × ceil(height/chunk_size)`。
- **边界块**：右侧/底部最后一块按地图实际边界**裁剪**，`cell_w`/`cell_h` 可小于 `chunk_size`；不填充、不与 `default` 混淆（缺块才回落到 `default`）。
- 块内一律**行优先（row-major）**，`flags` 位 0 保留表示是否行优先（v0.1 恒为行优先，置 1）。

## 3. 单个块文件格式（`.bin`）

### 3.1 文件头（32 字节，**little-endian**）

| 偏移 | 长度 | 字段 | 类型 | 说明 |
|---|---|---|---|---|
| 0 | 4 | `magic` | ASCII | 固定 `WVC1`（World View Chunk v1） |
| 4 | 2 | `format_version` | u16 | 格式版本，v0.1 为 `1` |
| 6 | 1 | `dtype` | u8 | 单元类型码，见 §3.2 |
| 7 | 1 | `flags` | u8 | 位标志：bit0=行优先（置 1）；其余保留 0 |
| 8 | 2 | `cell_w` | u16 | 本块列数（边界块 < `chunk_size`） |
| 10 | 2 | `cell_h` | u16 | 本块行数（边界块 < `chunk_size`） |
| 12 | 4 | `cx` | i32 | 块列坐标 |
| 16 | 4 | `cy` | i32 | 块行坐标 |
| 20 | 4 | `cell_count` | u32 | `cell_w × cell_h`（冗余校验用） |
| 24 | 4 | `payload_crc32` | u32 | 载荷 CRC32（见 §5） |
| 28 | 4 | `reserved` | u32 | 保留，v0.1 置 0 |

紧接着文件头是**载荷**（payload）：`cell_count × sizeof(dtype)` 字节，行优先排列。

**文件总长** = `32 + cell_count × sizeof(dtype)` 字节（无对齐填充）。

### 3.2 dtype 类型码

| 码 | 名称 | 字节 | 用途 |
|---|---|---|---|
| 0 | `u8` | 1 | 地形类型序号（≤255，见 §3.3） |
| 1 | `i16` | 2 | 高度（含负值，如海平面以下） |
| 2 | `u16` | 2 | 高度（非负） |
| 3 | `f32` | 4 | 高度 / 通行成本（需小数） |

> 新增类型码属格式变更，须升 `format_version` 并回填本节。

### 3.3 图例（legend，**不在二进制内**）

- `u8` 地形类型序号到地形类型（`mountain`/`forest`/…）的映射表，写在**地图 YAML**（或工程级图例），**不写入 `.bin`**。
- 图例变化（如新增地形类型）不得改写已有 `.bin`；序号一经发布不复用。

## 4. 块索引（YAML 侧）

块索引由 YAML 声明，是**唯一入口**；`.bin` 不被隐式发现（不扫描目录猜块）。

```yaml
# maps/world/main.yaml（片段，字段语义见数据模型规格 §3.5）
terrain_data:
  encoding: chunked
  chunk_size: 64
  chunk_dir: maps/world/main.terrain.chunks/
  dtype: u8
  default: { type: plain, move_cost: 1, buildable: true }
  chunk_index:
    - { cx: 0, cy: 0, ref: maps/world/main.terrain.chunks/0_0.bin, crc32: 0x1a2b3c4d, dtype: u8 }
    - { cx: 1, cy: 0, ref: maps/world/main.terrain.chunks/1_0.bin, crc32: 0x5e6f7a8b, dtype: u8 }
```

| YAML 字段 | 与二进制的关系 |
|---|---|
| `chunk_size` | 必须与块头 `cell_w`/`cell_h` 一致（边界块除外，边界块应 ≤ 该值） |
| `dtype` | 必须与块头 `dtype` 一致 |
| `chunk_index[].cx`/`cy` | 必须与块头 `cx`/`cy` 一致 |
| `chunk_index[].ref` | 块文件相对路径（必须落在 `chunk_dir` 内） |
| `chunk_index[].crc32` | 必须与块头 `payload_crc32` 一致 |
| `default` | 未在 `chunk_index` 中列出的块/单元回落到此默认值 |

- **完整性**：`chunk_index` 应覆盖地图全部块；允许**省略全为默认值的块**（读取时按 `default` 生成）。
- **命名约定**：`<cx>_<cy>.bin`；但**以 `ref` 为准**（命名仅供人读）。

## 5. 校验（保存 / 打开工程时执行）

对每个块文件：

- [ ] `magic == "WVC1"`，`format_version` 受支持。
- [ ] 文件长度为 `32 + cell_count × sizeof(dtype)`；`cell_count == cell_w × cell_h`。
- [ ] `cell_w`/`cell_h` ≤ `chunk_size`；非边界块应等于 `chunk_size`。
- [ ] 块头 `dtype` / `cx` / `cy` 与 `chunk_index` 声明一致。
- [ ] 按 `dtype` 计算的 **载荷 CRC32 等于块头 `payload_crc32`**，且等于 `chunk_index[].crc32`（三者一致）。
- [ ] `chunk_index` 无重复块坐标、覆盖完整（含 `default` 补齐判断）。

**错误输出要求**：指明**地图 YAML 文件 + `chunk_index` 条目 + 块文件路径 + 块坐标 `(cx,cy)`**，便于定位；CRC/长度不符时给出期望值与实际值。

## 6. 版本与兼容

- `format_version` 为**格式**版本，独立于软件版本；v0.1 对应软件 0.1，`format_version = 1`。
- **只增不改**：新增 dtype 或字段须升 `format_version`，并保证旧块仍可读（新增项置于保留区或扩展区）。
- 读取时遇未知 `format_version`：报错并拒绝，不猜测解析。
- 字节序**固定 little-endian**，不随平台变化；跨平台工程可直接拷贝。

## 7. 与 YAML 的对应总表

| 数据模型（§3.5） | 二进制（本文） |
|---|---|
| `encoding: chunked` | 触发解析本格式 |
| `chunk_size` | 块头 `cell_w`/`cell_h` 上限 |
| `dtype` | 块头 `dtype` |
| `chunk_dir` | 块文件所在目录 |
| `chunk_index[].{cx,cy,ref,crc32,dtype}` | 块头 `{cx,cy,文件路径,payload_crc32,dtype}` |
| `default` | YAML 独有（缺失块的回落值） |
| 地形类型图例 / 单位 / 语义 | **仅 YAML**，二进制不承载 |
