# 图层系统规格 v0.1

> 图层是 World View 的核心组织手段：所有空间数据分层承载，可独立开关、锁定、调透明度与顺序，并声明**时间有效性**。
> 图层字段定义以 [数据模型规格 §4](数据模型规格_v0.1.md) 为唯一真源。

---

## 1. 图层通用字段与渲染规则

每个图层含：`id` / `name` / `type` / `visible` / `locked` / `opacity` / `z_order` / `valid_from` / `valid_to` / `data` / `params`。

**合成规则**：图层参与渲染当且仅当

```
visible == true
AND (valid_from 为空 OR 当前时刻 >= valid_from)
AND (valid_to   为空 OR 当前时刻 <= valid_to)
```

**管理能力**（全部图层通用）：

- 显示 / 隐藏（`visible`）
- 锁定（`locked`，锁定后不可编辑但仍渲染）
- 透明度（`opacity` 0–1）
- 叠加顺序（`z_order`，大者在上）
- **时间有效性**（`valid_from` / `valid_to`）
- **按时间轴自动切换**：拖动时间轴时，落在有效区间外的图层自动隐藏

## 2. 基础图层（v0.1 必须实现）

### 2.1 基础地形层（`terrain`）

显示地形、高度、植被、水域。数据来源：地图的 `terrain_data` + `height_data`。

- 渲染：按地形类型着色 + 高度阴影（山体明暗）。
- 编辑：笔刷直接写入（见 [地图编辑器规格](地图编辑器规格_v0.1.md) §2.1）。

### 2.2 疆界层（`border`）

用户可**粗略绘制**势力范围（方框或套索），系统据此**自动贴合**生成疆界。

**贴合依据**（v0.1 简化规则，按优先级）：高度图（山脊线）→ 河流 → 海岸线。

**贴合流程**：

```
用户粗绘多边形（意图）
   ↓
采样边界点
   ↓
在邻域内搜索贴合物（山脊线/河流/海岸线）
   ↓
吸附 + 平滑，生成最终疆界多边形
   ↓
写入疆界图层 data.factions[].polygon
```

**简化规则（v0.1）** `[待标定]`：

1. 高度阈值：边界优先沿「高度高于阈值」的连续山脊走。
2. 河流：若边界附近有河流折线，且距离在容差内，则贴到河流中心线。
3. 海岸线：若边界逼近水域，则贴到海岸线。
4. 无贴合物时：保留用户粗绘的平滑结果。

**支持**：多国、多势力、争议领土（多个势力多边形重叠区标记为 `disputed`）。

### 2.3 影响力层（`influence`）

以**某个中心点**画圆（如教廷、商会、军事要塞），系统按半径、强度、衰减曲线生成影响力范围。

| 参数 | 说明 |
|---|---|
| `center` | 中心点坐标 |
| `radius` | 半径 `[待标定]` |
| `strength` | 中心强度 `[待标定]` |
| `decay` | 衰减曲线（线性 / 高斯 / 反比）`[待标定]` |
| `clip_to_border` | 是否自动裁剪到疆界内 |
| `owner` | 归属势力/组织 |

**裁剪**：可自动裁剪到指定疆界内，或与其他影响力**叠加显示**（叠加值用于热力图着色）。

### 2.4 道路层（`road`）

承载：官道、小径、商路、航线、地下通道。

| 字段 | 说明 |
|---|---|
| `road_type` | 道路类型（官道/小径/商路/航线/传送路径/地下通道） |
| `path` | 折线节点数组 |
| `width` | 道路宽度（显示/占地） |
| `rank` | 等级（决定默认速度与维护优先级） |
| `speed` | 通行速度（供运输时间计算） |
| `maintenance` | 维护状态：`good`/`worn`/`broken` |
| `move_cost_mod` | 通行成本修正 |
| `bidirectional` | 是否双向 |

> 道路层是**陆上运输路线**的寻路依据（`Map.travel.road_layer_ref` 引用本层）；运输路线本身登记在 `travel` 路线层（见 §3 清单第 16 项），二者分工：道路层描述可通行基础设施，路线层描述具体运输路径（`Route`）。

### 2.5 事件层（`event`）

承载：事件点、事件链、任务起点、历史遗迹。

- 数据来源：事件的 `location` + `scope`（见 [数据模型规格 §6](数据模型规格_v0.1.md)）。
- 渲染：事件点图标 + 影响范围（circle/polygon/rect）。
- **事件链**：由事件的 `prev_events` / `next_events` 连成线，展示因果脉络。
- 随时间轴回放：只显示「当前时刻已发生」的事件。

### 2.6 推荐图层叠加顺序（`z_order`，从下到上）

`z_order` 大者在上。**通用默认顺序**（同一地图可自定义）：

| `z_order` | 图层 `type` | 名称 | 说明 |
|---|---|---|---|
| 0 | `terrain` | 基础地形 | 地形/高度/水域/植被的合成底图（含高度阴影） |
| 10 | `road` | 道路 | 官道/小径/商路/航线/地下通道 |
| 20 | `building` | 建筑 | 城市/街区建筑轮廓与入口，来源 `building_refs` |
| 30 | `border` | 疆界 | 势力范围 |
| 40 | `influence` | 影响力 | 中心圆 + 衰减/裁剪 |
| 50 | `political` | 政治势力 | 国家/领地/宣称/停战线 |
| 60 | `religion` | 宗教/信仰 | 教区/圣地/朝圣路线 |
| 70 | `culture` | 文化/语言 | 民族/语言/风俗边界 |
| 80 | `economy` | 经济/贸易 | 商路/市场/关税区 |
| 90 | `military` | 军事 | 要塞/驻军/战争前线/战争迷雾 |
| 100 | `magic` | 魔法/超自然 | 魔力浓度/灵脉/裂隙 |
| 110 | `danger` | 危险度 | 巢穴/盗匪营地/禁区 |
| 120 | `event` | 事件 | 事件点/事件链/影响范围 |
| 130 | `character` | 人物 | 人物位置/状态/所属势力 |
| 140 | `travel` | 路线 | 运输路线（陆/水/空/地/传送；引用道路层、水域、`teleport_points`） |
| 150 | `vehicle` | 载具 | 载具图标（位于 `travel` 之上，使运动中的载具覆盖路线） |
| 160 | `quest` | 任务/传闻 | 任务点/传闻扩散 |
| 170 | `snapshot` | 时间快照 | 只读快照层 |
| 180 | `ui` | UI 标记 | 光标/选区/测量线等辅助标记（不落盘） |

> - **高度层、水域层、植被层**在 v0.1 内**合并进 `terrain` 合成渲染**，不单独设层；确需独立开关时再登记为独立图层。
> - `building` / `character` / `vehicle` / `ui` 为本表新增登记的图层类型，见 §3。
> - `vehicle` 位于 `travel` 之上：行进中载具隐藏后路线仍可见；静止时载具仍位于路线节点上。

### 2.7 视觉增强的时间语义

以下视觉增强**并非游离特效**，均需绑定到时间轴当前时刻；其状态要么从 `params` 推导，要么从「基准状态 + 差异事件」重演（见 [时间轴系统规格](时间轴系统规格_v0.1.md)），不得改写领域数据。

| 增强 | 归属 | 时间语义 | 实现要点 |
|---|---|---|---|
| **昼夜变化** | `terrain` 滤镜（或专属 `lighting` 预留类型） | 按当前时刻（小时/分钟）到 `dawn`/`dusk` 区间映射亮度与光照 | 阈值（dawn、dusk、夜间范围）写在图层 `params`，阈值标注 `[待标定]` |
| **战争迷雾** | `military` 遮罩（`mask` 形态） | 区域揭示由「当前可见势力」与「历史探索记录」决定；与任务过程可联动 | 掩码字段写在图层 `data`，揭示状态由事件 `effects` 修改 |
| **影响力扩散** | `influence` / `quest` / `danger` 热力场 | 热力随时间复动：动画**按当前时刻重演**，不存储中间帧 | 现算现绘；幂等 |
| **载具移动** | `vehicle` 图标 + `travel` 路线动画 | 载具位置/状态来自运输任务 + 时间重演；不存储轨迹快照 |
| **事件点闪烁** | `event` 图标动画 | 按时间轴「当前时刻是否已发生」决定点状态与高亮强度 | 已发生 = 高亮；未发生 = 灰 |
| **河流动态** | `terrain` 渲染参数 | 动画速率不与时间轴绑定（自走型动效）；可独立控制开/关 | 保持冷静 |

> **口径**：上表中**与时间轴绑定**的增强（昼夜、迷雾、影响力扩散、事件点高亮、载具移动）都属于「时间轴事件重演」输出，不依赖在文件中存储动画帧。渲染层仅执行**状态计算 + 绘制**。
> **不在表中的纯表现型动效**（河流、微风吹雪）不受时间轴控制，算法阈值与边界由场景审美需求标定（写代码时以默认值实现，不需列入数据模型）。
> 战场上认「战争迷雾」状态以 `military` 区域令为依据，由「玩家/角色所在位置」、「所在势力」、「任务进度」三者决定；归属逻辑 = 跨领域（任务=计算）。

### 2.7.1 视觉增强的实现纪律（v0.1）

> 本节为 P0 收敛后追加的纪律条款，与 [技术基调确认_v0.1.md](技术基调确认_v0.1.md) §3 / §8 对齐。

- **数据声明在本规格，渲染实现留空**。v0.1 仅登记上表中的视觉增强字段（`params`、`valid_from` / `valid_to`、`data.mask`、`data.field` 等）；**PixiJS 滤镜 / shader、shader-based 灯光、particle 系统等渲染实现留到 M3+ 再决定**。
- **数据契约中立**。所有视觉相关字段必须能在《数据模型规格》找到对应位置（`Layer.params`、`valid_from` / `valid_to`、`custom_attributes` 等），不得把 PixiJS / Three.js / WebGL 专有对象塞进字段定义。
- **时间绑定与回放一致**。视觉增强的「当前状态」由时间轴（§2.7 表头口径）推导，**不存储动画快照、不在文件中落中间帧**。
- **算法阈值可配置**。阈值（dawn / dusk 区间、迷雾衰减、热力场半径、亮度因子等）写在 `Layer.params`，**全部标注 `[待标定]`**，禁止硬编码。

### 2.8 空间索引与性能

空间查询（视口裁剪、笔刷命中、邻域查找、势力范围计算）不使用原始网格扫描；**所有地图按规模选以下空间索引**：

| 规模 | 索引 | 适用 |
|---|---|---|
| 小（< 1万 对象） | 平铺 array | 街区、室内 |
| 中（1万 - 100万 对象） | **四叉树** | 城市、区域 |
| 大（> 100万 对象） | **R 树** | 世界（多层地块、世界各对象） |

- **索引项**：点（事件点/标记）、折线（道路、河流）、多边形（疆界、势力）、热力场与遮罩（区域 AABB 边界）。
- **索引构建时机**：工程打开 / 编辑操作 / 背景任务；变更后**原地增量更新**，不跨调度。
- **查询能力**：范围（视口裁剪）、命中（点选/框选）、邻近（一定半径内）、交叉（折线/多边形相交）。
- **渲染按查询结果**仅取视口内对象，**避免随地图变大变卡**。

> 空间索引选型与阈值在实现阶段需验证（性能预算见 [总体设计 §8](总体设计_v0.1.md)）。

以下图层为 RPG/世界观深度使用准备。登记在此，实现按里程碑排期（M3 之后逐步补齐）。**新增图层必须先登记进本表**，并声明：`type` 键、数据形态、是否参与贴合/裁剪、是否带时间有效性。

| # | 图层 type | 名称 | 承载内容 | 特别说明 |
|---|---|---|---|---|
| 1 | `political` | 政治势力层 | 国家、领地、封臣、宣称、停战线、争议区 | 与疆界层共用贴合；宣称需时间有效 |
| 2 | `religion` | 宗教/信仰层 | 教廷、教区、圣地、朝圣路线、异端区域 | 朝圣路线为矢量折线 |

| 4 | `economy` | 经济/贸易层 | 商路、资源点、市场、关税区、税收范围 | 商路与道路层部分重叠，需约定主数据归属 |
| 5 | `military` | 军事层 | 要塞、兵营、驻军、巡逻路线、战争前线、战争迷雾 | 「战争迷雾」为视图遮罩层 |
| 6 | `magic` | 魔法/超自然层 | 魔力浓度、灵脉、裂隙、封印、传送门、诅咒地 | 浓度多为热力图 |

| 8 | `quest` | 任务/传闻层 | 任务发布点、传闻扩散范围、NPC 活动路线 | 扩散范围=影响力圆的一种 |
| 9 | `law` | 法律/治安层 | 管辖权、通缉区、禁令区、宵禁范围 | 常随时间轴切换（宵禁入夜生效） |
| 10 | `ecology` | 生态/气候层 | 气候带、植被带、动物迁徙路线、季节变化 | 季节变化=多套有效时间切片 |
| 11 | `underground` | 地下/城图层 | 洞穴、地城、矿道、下水道、地下城 | 常引用独立 `underground` 地图 |
| 12 | `faction` | 种族/阵营层 | 种族分布、阵营控制区、友好/敌对关系 | 与政治层区分：此处为分布非主权 |
| 13 | `reputation` | 好感/声望层 | 各势力对玩家或角色的态度热力图 | 数据源=人物/势力关系值 |
| 14 | `resource` | 资源/产出层 | 矿产、农田、木材、魔力水晶、渔场 | 与地形 `resources` 标签关联 |
| 15 | `disaster` | 灾害/瘟疫层 | 疫区、灾区、污染区、火灾蔓延路径 | 蔓延路径带时间序列 |
| 16 | `travel` | 传送/路径层 | 运输路线（陆上/飞行/水上/地下/传送）、航线、传送阵、秘境入口、单向通道 | 承载 `Route` 对象（见 [数据模型规格 §9](数据模型规格_v0.1.md)）；陆上路线引用道路层、水上路线引用水域层、传送路线引用 `teleport_points`；单向通道需 `bidirectional: false` |
| 17 | `myth` | 神话/传说层 | 神话地点、英雄遗迹、预言发生地 | 多为点标记 |
| 18 | `snapshot` | 时间快照层 | 同一地图在不同时间点的势力、城市归属、事件点状态 | **特殊层**：只读，由快照生成，不参与编辑 |
| 19 | `building` | 建筑层 | 建筑轮廓、占地、入口、楼层 | 来源 `building_refs`；与道路层配合自动生成街区；建筑 `state` 可带时间有效性 |
| 20 | `character` | 人物层 | 人物位置、状态、所属势力 | 数据源=人物 `residence` 与事件 `effects`；随时刻显示当前所在位置 |
| 21 | `vehicle` | 载具层 | 载具图标、位置、行进状态 | 数据源=Vehicle（[数据模型规格 §8](数据模型规格_v0.1.md)）；随运输任务沿路线移动，随时间轴回放 |
| 22 | `ui` | UI 标记层 | 选区、框选、测量线、光标、临时标注 | **辅助层**：不落盘、不参与保存与校验 |

> **注意**：清单中的「争议区 / 停战线 / 战争前线 / 边界带」等，实现时应统一为**多边形的属性标记**（如 `disputed: true`、`state: ceasefire`），而不是各造一套几何类型。几何类型收敛为：点、折线、多边形、热力场、遮罩。

## 4. 图层数据形态收敛

为避免图层各自造轮子，**所有图层的 `data` 只能由以下五种基础形态组合而成**：

| 形态 | 结构 | 用于 |
|---|---|---|
| 点集 `points` | `[{x, y, label, attrs}]` | 事件点、圣地、遗迹、巢穴 |
| 折线 `polylines` | `[{path: [...], label, attrs}]` | 道路、航线、河流、巡逻路线 |
| 多边形 `polygons` | `[{rings: [...], label, attrs, valid_from, valid_to}]` | 疆界、文化圈、禁区 |
| 热力场 `field` | 采样网格或中心+衰减参数 | 影响力、魔力浓度、声望 |
| 遮罩 `mask` | 位图/网格布尔 | 战争迷雾、视野 |

**统一属性包 `attrs`**：任意形态都带 `attrs`，承载 `owner` / `state` / `disputed` / `resource` 等开放键，避免为每种语义再造字段。

## 5. 算法规则归属

| 算法 | 归属 | 说明 |
|---|---|---|
| 疆界自动贴合 | 本文档 §2.2 | 高度阈值 + 山脊线 + 河流 + 海岸线，简化规则 |
| 影响力衰减与裁剪 | 本文档 §2.3 | 线性/高斯/反比曲线，可裁剪到疆界 |
| 图层的有效时间判定 | 本文档 §1 | 与时间轴求交集 |

所有算法阈值一律**可配置**且标注 `[待标定]`，写入图层 `params` 或工程设置，禁止硬编码。

算法中的长度与高度阈值使用**所在地图**的距离单位与高度单位（`grid.distance_unit` / `grid.height_unit`，见 [数据模型规格 §2.2](数据模型规格_v0.1.md)）；高度阈值、影响力半径等一律先归一到该地图 `grid.base_unit` 再计算，保证与地形、高度图同一套单位。
