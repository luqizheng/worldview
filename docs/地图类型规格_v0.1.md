# 地图类型规格 v0.1

> 本文定义 World View 六类地图的**技术画像**：分辨率、单格距离、数据编码、渲染策略、编辑工具、默认图层、默认时间粒度、缩放层级与跨图引用。
> 字段以 [数据模型规格_v0.1.md](数据模型规格_v0.1.md) 为唯一真源；编辑交互见 [地图编辑器规格](地图编辑器规格_v0.1.md)；渲染实现随选型收敛（**P0-2 Godot 内置 2D**：`CanvasItem` / `TileMap` / `Polygon2D` / `Line2D`，2026-10-09 反转）落地。

---

## 0. 定位

每类地图都是**统一地图内核**（[总体设计 §3.5](总体设计_v0.1.md)）的实例，差异由**类型化扩展点**承载：

| 扩展点 | 说明 |
|---|---|
| **数据格式** | `terrain_data` / `height_data` 默认编码（`grid` / `sparse` / `chunked`，见 [数据模型规格 §3](数据模型规格_v0.1.md)） |
| **渲染策略** | 瓦片 / Sprite / 矢量 合成方式 |
| **编辑工具** | 该类型地图启用的工具集 |
| **默认图层** | 初始图层集合（开关、透明度、叠加顺序） |
| **默认时间粒度** | 地图 `time.default_granularity` 与 `min_granularity` |
| **缩放层级** | LOD 区间与图标 / 瓦片 / 精灵切换阈值 |

> 六类地图之间的差异见 §1–§6。`street`（街区）是 `city` 与 `building` 之间的**可选层级**，`region` 是 `world` 与 `city` 之间的**可选层级**；可选层级既可独立成地图文件（`parent_map` 指向所属父图），也可并入父图的高精度档（具体口径以 §4 与 §2 为准）。
>
> **层级关系定案**（详见 [技术基调确认_v0.1.md](技术基调确认_v0.1.md) §6.1）：
>
> ```
> world          世界地图
>     └── 区域地图 (region)         可选层级
>         └── 城市地图 (city)
>             └── 街区地图 (street)        可选层级
>                 └── 建筑 / 室内图 (building)
> underground    地下 / 洞穴图（可交叉引用以上任一层级）
> ```

## 1. 世界地图（`type=world`）

- **特点**：大尺度、低精度；展示国家、地理、势力。
- **网格**：`512×512` 或 `1024×1024`；单格 `10–50 km`；`base_unit: m`。
- **数据**：`terrain_data`（地形）+ `height_data`（高度）；体积大时用 `chunked` 二进制分块（见 [二进制格式规格](二进制格式规格_v0.1.md)）。
- **渲染**：WebGL 瓦片 + 矢量叠加；`chunked` 数据按视口加载；远景 LOD 降采样。
- **默认图层**：地形 / 高度阴影 / 疆界 / 影响力 / 道路（少量） / 标记点（城市、遗迹）。
- **默认时间粒度**：`month`（默认）/ `day`（最小）。
- **缩放层级**：`very_far` 显示色块 / 简图；`far` 显示地形与疆界；`mid` 显示城市标记；`near` 与其他地图无重叠（街区模式可被 `world` 关闭）。
- **编辑工具**：笔刷（地形/高度）、方框/套索绘制疆界、圆形影响力工具、道路（少量）、测量工具。
- **跨图引用**：城市条目（`city_refs`）→ 城市地图（`city`）；可选 `region` 子图。

---

## 2. 区域地图（`type=region`）

- **特点**：中等精度，连接世界与城市。
- **网格**：`1024×1024`；单格 `1 km`；`base_unit: m`。
- **数据**：`terrain_data` + `height_data` + 道路矢量；体积大时 `chunked`。
- **渲染**：WebGL 瓦片 + 矢量道路与势力范围。
- **默认图层**：地形 / 高度阴影 / 道路 / 势力 / 资源点 / 事件点。
- **默认时间粒度**：`day`（默认与最小）。
- **缩放层级**：`far` 显示地形；`mid` 显示道路与城镇；`near` 显示具体建筑。
- **编辑工具**：笔刷、道路（沿地形自动生成）、方框绘制势力范围、测量工具。
- **跨图引用**：城镇 → `city` 城市地图。

---

## 3. 城市地图（`type=city`）

- **特点**：高精度；建筑、街道、居民。
- **网格**：`1024×1024` 或更大；单格 `1–10 m`；`base_unit: m`。
- **数据**：`building_refs`（建筑条目，见 [数据模型规格 §2.6](数据模型规格_v0.1.md)）+ 街道矢量 + 居民生成结果（系统侧数据，落 `characters/` 下按人物档案呈现）。
- **渲染**：Godot 2D `Sprite2D`（建筑精灵）+ `Line2D` / `Polygon2D` 矢量街道；矢量-精灵分层合成（`CanvasItem.z_index`）。
- **默认图层**：地形底图 / 街道 / 建筑 / 巷子 / 势力 / 事件 / 居民点 / 标签。
- **默认时间粒度**：`hour`（默认与最小）。
- **缩放层级**：`mid` 街区块面；`near` 单栋建筑；`very_near` 入口与门牌。
- **编辑工具**：建筑放置（旋转、吸附、图片模板）、街区魔法盒 + 居民生成、街道绘制、测量工具。
- **跨图引用**：建筑 → `building`（室内图）；地图区域 → `street`（街区档，可选）。

---

## 4. 街区地图（`type=street`，可选层级）

- **特点**：城市局部、极高精度；介于城市与建筑之间。
- **网格**：城市地图局部；单格 `0.5–1 m`；`base_unit: m`。
- **数据**：`building_refs`（较密集）+ 街道矢量 + 巷子矢量 + 摊位/临时建筑。
- **渲染**：Godot 2D `Sprite2D` + `TileMap`（按需）。
- **默认时间粒度**：`hour` / `minute`（"下一次默认" `minute`，覆盖场景：追逐、巡逻、店铺营业）。
- **缩放层级**：`near`/`very_near`（与 `city` 高端重叠时改用 `street`）。
- **编辑工具**：建筑（模板/上传）、摊位摆放、巷子绘制、巡逻路径（路线绘制）、测量工具。
- **跨图引用**：可作 `city` 的高精度档，也可独立文件（`parent_map` 指向所属城市）；街区内建筑 → `building`。
- **存盘位置**：`maps/street/*.yaml`（见 [存储与目录规范 §1](存储与目录规范_v0.1.md)）。

---

## 5. 建筑室内图（`type=building`）

- **特点**：室内、家具、房间、门、门锁。
- **网格**：视房间尺寸；单格 `0.5–1 m`；`base_unit: m`（可缩为 `cm`）。
- **数据**：地板 / 墙壁 / 家具 / 门 / 楼梯 / 道具。
- **渲染**：2D 俯视为主；v0.1 不启用 `isometric`/`3d`（仅 [数据模型规格 §2.8](数据模型规格_v0.1.md) 预留）。
- **默认时间粒度**：`minute`（默认与最小）。
- **缩放层级**：`near`/`very_near`；单房间近看。
- **编辑工具**：家具拖放、门放置、密室与陷阱、交互点设置。
- **跨图引用**：被 `city` / `street` 的 `building_refs[].interior_ref` 引用（见 [数据模型规格 §2.6](数据模型规格_v0.1.md)）。

---

## 6. 地下 / 洞穴图（`type=underground`）

- **特点**：不规则、迷宫、矿道、地下城。
- **网格**：视洞穴范围；单格 `1–5 m`；`base_unit: m`。
- **数据**：网格 + 矢量洞穴轮廓。
- **渲染**：Godot 2D 矢量（`Polygon2D` / `Line2D`）+ `TileMap`（按需）。
- **默认时间粒度**：`day`（默认）/ `minute`（最小）。
- **缩放层级**：`mid`（区域划分）→ `near`（走廊）→ `very_near`（房间）。
- **编辑工具**：除笔刷 / 出行工具外，可走**程序生成**（噪声 / 分形 / 细胞自动机，列入编辑器 §5，作为「范围外」需授权能力）。
- **跨图引用**：可被地面建筑的 `interior_ref` / 区域图 / 事件点指向。

---

## 7. 缩放层级（LOD）总览

| LOD | 表现 |
|---|---|
| `very_far` | 图标 / 色块（远景不拉原图） |
| `far` | 简瓦片 / 简轮廓 |
| `mid` | 全瓦片 + 矢量 |
| `near` | 矢量 + 矢量 |
| `very_near` | Sprite + 文字标注 |

- v0.1 只对 `world`/`region` 启用完整 LOD；`city`/`street`/`building` 在 `mid` 以下启用默认 `very_near`。
- LOD 阈值与 LOD 数据源都可配置（写在地图 YAML 的 `presentation` 下；阈值标注 `[待标定]`）。

## 8. 跨图引用矩阵

| 子图 \ 父图 | world | region | city | street | building | underground |
|---|---|---|---|---|---|---|
| **world** | – | × | 入口 | × | × | 入口 |
| **region** | 子图 | – | 入口 | × | × | × |
| **city** | 子图 | 子图 | – | 入口 | × | × |
| **street** | × | × | 子图 | – | × | × |
| **building** | × | × | 子图 | 子图 | – | 入口 |
| **underground** | 子图 | × | × | × | 子图 | – |

- `子图` = 可作下一层；`入口` = 可作为入口点但不另存为子；`×` = 不重。
- 跨图跳转运行时按 `anchor` + `extent` 计算地形与范围（见 [数据模型规格 §2.10](数据模型规格_v0.1.md)）。

## 9. 类型化扩展点总表（实现输入）

| 类型 | 数据编码 | 渲染 | 编辑工具 | 默认时间粒度 | LOD | art_style_default |
|---|---|---|---|---|---|---|
| `world` | `chunked`（大图）/ sparse | WebGL 瓦片 + 矢量 | 笔刷、疆界、影响力、路口 | `month` / `day` | 5 级 | `jrpg` |
| `region` | `sparse` / `chunked` | WebGL 瓦片 + 矢量 | 笔刷、道路、势力范围 | `day` / `day` | 4 级 | `jrpg` |
| `city` | `sparse` / `grid` | Godot 2D `Sprite2D` + `Line2D` / `Polygon2D` 矢量街道 | 建筑、街区魔棒、街道、居民生成 | `hour` / `hour` | 3 级 | `jrpg` |
| `street` | `grid` / `sparse` | Godot 2D `Sprite2D` + `TileMap` | 摊位、巡逻路径、建筑模板 | `hour` / `minute` | 2 级 | `[待实装]` |
| `building` | `grid` | Godot 2D 俯视（`TileMap` + `Sprite2D`） | 家具、门、密室 | `minute` / `minute` | 2 级 | `jrpg` |
| `underground` | `grid` + 矢量 | Godot 2D `Polygon2D` / `Line2D` + `TileMap` | 笔刷 + 程序生成（需授权） | `day` / `minute` | 3 级 | `[待实装]` |

> **`art_style_default` 列说明**（v0.1 增补）：
> - v0.1 **JRPG 优先**——`world` / `region` / `city` / `building` 四类型的默认内容美术风格为 `jrpg`（与既有行为一致）。
> - `street` / `underground` 两类型的 `art_style_default` 标 `[待实装]`，由 `art_style` 字段的 UI 选默认值时按当前工程级默认（`jrpg`）兜底；具体细化推迟到 T-ART-7 之后的细化工单。
> - 字段定义、枚举、用户改写路径见 [数据模型规格 §2.8](数据模型规格_v0.1.md)；风格 ID 的资源契约、样式定义在 [美术资源规范 §1.1](美术资源规范_v0.1.md)；编辑器交互见 [地图编辑器规格 §7.2.1](地图编辑器规格_v0.1.md)。

## 10. 待标定项

| 项 | 说明 |
|---|---|
| 各类型 LOD 阈值 `[待标定]` | 切换图标 / 瓦片 / 精灵的屏幕像素 / 世界米 阈值 |
| `street` 默认是否独立文件 | 默认仅作为 `city` 的高精度档；独立文件遵循 [存储与目录规范 §1](存储与目录规范_v0.1.md) |
| `underground` 程序生成范围 | 噪声 / 分形 / 细胞自动机 的默认参数与边界 `[待标定]` |
| 建筑 `interior_ref` 允许跨级 | 如 `street` ↔ `building` 直接跳转，是否允许 `[待标定]` |
