# 地图编辑器规格 v0.1

> 覆盖世界地图与城市地图两级编辑、多地图层级引用，以及地图的**视图/坐标、载具运输呈现与呈现模式**。
> 字段定义以 [数据模型规格_v0.1.md](数据模型规格_v0.1.md) 为唯一真源；图层规则见 [图层系统规格_v0.1.md](图层系统规格_v0.1.md)；界面布局与交互流程见 [界面与交互规格_v0.1.md](界面与交互规格_v0.1.md)。

---

## 1. 通用编辑能力（两级地图共用）

### 1.1 笔刷（Brush）

**笔刷模式**：

| 模式 | 说明 |
|---|---|
| 圆形 `round` | 圆形落笔（默认），适合地形/地块 |
| 方形 `square` | 方形落笔 |
| 套索 `lasso` | 自由多边形区域一次性填充/清除 |
| 魔术棒 `magic_wand` | 按「相近地形/高度」自动框选连通区域，适合批量替换同类地貌 |
| 沿路径 `path` | 沿绘制路径连续铺笔（如沿河铺植被、沿路铺街区） |
| 填充 `fill` | 对封闭区域整体填充（油漆桶） |

**笔刷参数**：

| 参数 | 说明 |
|---|---|
| 大小 `size` | 笔刷半径（格） |
| 强度 `strength` | 单次落笔的作用强度 |
| 平滑度 `smoothness` | 边缘过渡的平滑程度 `[待标定]` |
| 边缘衰减 `falloff` | 从笔心到边缘的作用衰减曲线 `[待标定]` |
| 随机抖动 `jitter` | 落点/强度的随机扰动，避免机械感 `[待标定]` |
| 地形混合 `blend` | 两种地形交界处的过渡/混合模式 `[待标定]` |
| 吸附网格 | 是否吸附到网格（取地图 `grid.snap`） |

- 笔刷用于**绘制地形**（世界地图）与**铺设街区/地块**（城市地图）。
- 长按拖拽连续绘制；笔刷落点可吸附网格，也可自由定位（由地图 `grid.snap` / `grid.cell_distance` 决定吸附，见 §1.4）。
- 所有笔刷操作进入**撤销/重做栈**（命令模式，见 §1.3）。

### 1.2 选区（Selection）

支持以下选区工具，用于批量操作（填充、清除、复制、统计、对齐）：

| 工具 | 说明 |
|---|---|
| 方框（rect） | 拖拽矩形 |
| 圆形（circle） | 拖拽圆 |
| 套索（lasso） | 自由多边形 |
| 魔术棒（magic_wand） | 按「相同地形类型」或**高度相近**的连通区域自动框选（复用 §1.1 笔刷中的魔术棒模式，二者同一实现） |

**选区上的变换**（作用于选区内对象，多为建筑、街区图块、标记点）：

| 操作 | 说明 |
|---|---|
| 复制 / 粘贴 | 跨地图粘贴受 `grid.snap` 约束 |
| 删除 | 二次确认（避免误删） |
| 旋转 | 围绕选区中心或围绕单个对象旋转（建筑支持任意角度） |
| 缩放 | 等比缩放（非整批） |
| 对齐 | 左 / 右 / 上 / 下 / 中心水平 / 中心垂直（多对象） |
| 吸附 | 选区内对象吸附到格，或吸附到「建筑边缘 / 街道中心线」等几何基准 |

选区支持：批量改地形类型、批量改高度、批量增删资源标签。

### 1.3 撤销 / 重做 / 快照（非破坏编辑）

- **命令模式撤销栈**（Command Pattern）：每次编辑产生一个**可序列化命令对象**（含执行 + 反演）。操作粒度 = 一次落笔 / 一次放置 / 一次批量修改。支持**多步撤销/重做**，并可保存到工程快照文件（与时间快照并列，见 [时间轴系统规格](时间轴系统规格_v0.1.md) §快照）。
- **快照**：为关键时间点或关键编辑节点保存快照，可对比、可回滚。
- 编辑层的撤销栈与时间轴的差异序列是**两套机制**，不要混淆：
  - 撤销栈 = 编辑过程的操作历史（内存/会话级，命令模式）。
  - 差异序列 = 世界设定的时间演化（持久化，见 [时间轴系统规格](时间轴系统规格_v0.1.md)）。

### 1.4 地图设置（网格、距离与时间）

每张地图**独立配置**，进入该地图时按此设置生效（字段见 [数据模型规格 §2.2/§2.3](数据模型规格_v0.1.md)）：

| 分组 | 设置项 |
|---|---|
| 网格与距离 | 网格宽/高、单格物理距离、距离单位、内部基础单位、高度单位、坐标原点、显示网格、吸附网格、比例尺 |
| 时间 | 默认时间粒度、最小时间粒度、时间显示格式、事件排序单位、是否继承工程历法、是否允许模糊时间 |
| 运输与通行 | 是否允许飞行（`allow_flight`）、是否允许水上（`allow_water`）、是否允许地下（`allow_underground`）、道路层引用（`road_layer_ref`）、航线/路线层引用（`route_layer_ref`）、传送点列表（`teleport_points`）（字段见 [数据模型规格 §2.7](数据模型规格_v0.1.md)） |

- 单格物理距离支持任意小数（如 `1.32 km`）；一切长度内部归一到 `base_unit` 再计算。
- 进入子地图时自动切换网格、比例尺、距离单位、吸附规则与时间轴粒度；返回父地图时切回（见 §4）。

## 2. 世界地图编辑

### 2.1 笔刷绘制地形

可绘制地形类型见 [数据模型规格 §3.1](数据模型规格_v0.1.md)：山、森林、平原、水域、沙漠、沼泽、丘陵、冻原、盆地、海岸、河流。

绘制时同时写入地形单元字段：`type` / `move_cost` / `resources` / `buildable`。

### 2.2 高度信息

- 每个网格有**高度值**，用于生成山脉、河流、气候、疆界贴合。
- 高度可**笔刷直接编辑**，也可由地形类型给出默认高度剖面（如「山」默认高、「水域」默认低）。
- 高度数据存于独立文件（`height_data.cells_ref`），不内嵌地图 YAML。

**高度编辑操作**：

| 操作 | 说明 |
|---|---|
| 抬升 / 降低 | 按笔刷增量抬高/下沉 |
| 平滑 | 邻域平均，柔化陡坎 |
| 平整 | 将选区高度统一到目标值 |
| 噪声生成 | 按噪声（如 Perlin/Simplex）生成起伏 `[待标定]` |
| 山脊生成 | 沿绘制路径生成山脊隆起 `[待标定]` |
| 河流自动生成 | 由高度梯度推导流向并下切河道 `[待标定]` |
| 等高线显示 | 叠加等高线（间隔可配）`[待标定]` |
| 高度色阶 | 按高度分层设色 |

> 高度信息用途：山脉生成、河流流向、疆界自动贴合、通行成本、视野遮挡、气候模拟。

### 2.3 道路编辑

道路类型：**官道、小径、商路、航线、传送路径、地下通道**。

- 道路为**矢量折线**，存于道路图层（字段以 [图层系统规格 §2.4](图层系统规格_v0.1.md) 为准）。
- 道路绘制：连续点击落点 → 生成折线；支持增删节点、平滑；可沿地形自动生成，也可手动绘制。
- 道路含**宽度、等级、通行速度、维护状态**与 `move_cost` 修正（沿道路移动成本降低）。

### 2.4 城市放置

- 在世界地图上放置**城市标记** → 写入 `city_refs`。
- 点击城市标记 → 弹出**基础信息卡**（名称、人口、势力、备注）。
- 基础信息卡上提供「进入编辑」按钮 → 创建/打开对应城市地图（写入 `map_ref`），切换到城市编辑模式。

### 2.5 运输路线绘制（路线绘制工具）

按路线类型（见 [数据模型规格 §9](数据模型规格_v0.1.md)）提供对应绘制方式：

| 路线类型 | 绘制方式 | 依据 |
|---|---|---|
| 陆上 `land` | 沿道路自动寻路；无道路时按地形 `move_cost` 寻路；可手动补点 | 道路层（`road_layer_ref`）、地形通行成本 |
| 飞行 `air` | 直线或折线（手动添加航点） | 两点直线距离；不受地形阻挡 |
| 水上 `water` | 沿河流/湖泊/海洋/航线寻路，需水域连通 | 水域层/航线层 |
| 地下 `underground` | 沿洞穴/矿道/隧道/地下河 | 地下地图 |
| 传送 `teleport` | 点对点连线（传送阵 A → B） | `teleport_points` |

- 路线存于路线图层（见 [图层系统规格](图层系统规格_v0.1.md) §3 `travel` 层），路线绘制结果写入 `Route`（`start`/`end`/`waypoints`/`distance`）。
- 路线可经过城市、驿站、关隘、桥梁、港口、降落点；驿站用于休息、换马、补给。
- 可**自动生成**（沿道路/水域寻路）或**手动绘制**；支持增删途经点。
- 跨地图路线在进入子地图时自动切换网格与距离单位（见 §1.4），距离累加前归一到 `base_unit`。

## 3. 城市地图编辑

### 3.1 建筑放置

可放置建筑类型（开放枚举，初始集合）：

> 住宅、商店、酒馆、神庙、城堡、兵营、市场、码头、监狱、魔法塔。

建筑字段（`building_refs`）以 [数据模型规格 §2.6](数据模型规格_v0.1.md) 为唯一真源：`id` / `name` / `type` / `geometry`（矩形或多边形）/ `rotation`（旋转）/ `floors`（层数）/ `entrance`（入口坐标）/ `interior_ref`（室内图）/ `faction`（所属势力）/ `owner`（所有者）/ `state`（`intact`/`damaged`/`ruined`/`occupied`……）/ `custom_attributes`。

- 建筑放置：选择类型 → 拖拽占地（可旋转、可多层）→ 可指定入口坐标与所属势力/所有者。
- 特殊建筑（含 `interior_ref`）点击弹出基础信息，再「进入内部」切换到室内图。

### 3.2 街道、巷子、广场、桥梁、城墙

城市地图的线状要素（矢量折线 / 多边形）：

| 要素 | 几何 | 说明 |
|---|---|---|
| 主街 | 折线（有宽度） | 城市主干道 |
| 次街 | 折线（有宽度） | 次级道路 |
| 巷子 | 折线（有宽度） | 次级通道；可连接建筑后门、暗道与隐藏区域 |
| 广场 | 多边形 | 开放空间 |
| 桥梁 | 折线 | 跨水/跨沟 |
| 城墙 | 折线/多边形 | 可带城门口（城门） |

- 这些要素归入城市地图的**道路层/建筑层**，字段规则与世界地图道路一致（见 [图层系统规格 §2.4](图层系统规格_v0.1.md)）。
- 街道**可吸附建筑边缘自动生成街区**；巷子可连接建筑后门与隐藏区域。

### 3.3 居民生成（依据规则自动生成）

根据以下因素自动生成居民名单：

1. **建筑类型**（住宅/酒馆/兵营产出的人口构成不同）
2. **区域人口密度**
3. **财富水平**
4. **势力归属**

产出的居民写入 `characters/` 目录，并在建筑/居住地上登记引用。生成参数与规则 `[待标定]`，但**必须可配置**。

生成后居民可**逐个编辑**（改姓名、属性、关系等，走人物登记流程）。

### 3.4 特殊建筑

特殊建筑可绑定：**人物、事件、任务、商店库存、传送点**。

- 通过 `custom_attributes` 承载扩展绑定（如 `shop_stock`、`quest_refs`、`teleport_target`）。
- 特殊建筑若存在 `interior_ref`，可继续进入室内编辑。

### 3.5 与大地图引用

- 世界地图 `city_refs[].map_ref` → 城市地图文件。
- 城市地图返回世界地图：面包屑导航（世界 → 城市）。
- 断链处理：`map_ref` 指向的文件不存在时，界面显式提示「城市地图缺失，是否创建？」，不静默失败。

## 4. 多地图层级引用

```
世界地图 (world)
  └── 区域地图 (region)        # 可选层级，v0.1 可先跳过
        └── 城市地图 (city)
              └── 建筑/室内图 (building / interior)
                    └── 地下/洞穴图 (underground)   # 可与城市/室内交叉引用
```

**引用链规则**：

1. 每层通过 `map_ref` / `interior_ref` 记录下一层文件路径。
2. 每层通过 `parent_map` 记录上一层，便于面包屑与「返回上级」。
3. **单点引用**：一个城市条目只指向一个城市地图文件；一个建筑只指向一个室内图。
4. **引用自包含**：所有路径为相对工程根的相对路径，禁止绝对路径（见 [存储与目录规范](存储与目录规范_v0.1.md) §3）。
5. **断链校验**：保存工程时统一校验全部 `map_ref` / `interior_ref` / `city_ref` / `building_ref`。

**导航交互**：世界地图点击城市 → 弹出基础信息 → 「进入编辑」切到城市地图 → 点击特殊建筑 → 「进入内部」切到室内图；面包屑可逐级返回。

## 5. 视图与坐标系统

地图编辑器不是单纯画图工具，而是**时空沙盘的入口**：同时处理多地图层级、多图层、多模式，并与时间轴、人物、事件、运输互相引用。

### 5.1 视图模式

| 模式 | 值 | 说明 | v0.1 |
|---|---|---|---|
| 2D 俯视 | `2d` | 默认；适合大多数编辑 | ✔ |
| 2.5D 等距 | `isometric` | 增强立体感，适合城市与建筑 | 设计预留，未实现 |
| 3D 预览 | `3d` | 观察高度、山脉、城市轮廓 | 设计预留，未实现 |

> 视图模式存于地图 `presentation.view_mode`（见 [数据模型规格 §2.8](数据模型规格_v0.1.md)）。

### 5.2 视图操作

平移、缩放、旋转（2.5D/3D）、聚焦选区、全图适配、小地图导航、比例尺显示、坐标显示。

### 5.3 坐标系统

| 坐标 | 说明 |
|---|---|
| 世界坐标 | 全局唯一；跨地图引用时使用 |
| 地图坐标 | 当前地图内部坐标（格） |
| 网格坐标 | 行列号 `(col, row)` |
| 像素坐标 | 渲染用（屏幕/纹理），仅存在于渲染层 |

- 跨地图引用统一用「**世界坐标 + 地图引用路径**」；进入子地图后自动切换为子地图坐标。
- 领域层以**地图坐标（格）**为准；像素坐标不落盘。

## 6. 载具、路线与运输呈现

### 6.1 路线呈现

按类型使用不同线型（线型取自 `Route.display`，见 [数据模型规格 §9](数据模型规格_v0.1.md)）：陆上沿道路（虚线/实线）、飞行直线或折线、水上沿航线、地下沿通道、传送为点对点连线。

### 6.2 载具呈现

- 载具以**图标**显示在地图上（`Vehicle.icon`）。
- 行进中可**沿路线动画移动**；点击载具显示速度、载人/载货、休息规则、当前任务与 `status`。

### 6.3 运输时间计算呈现

选择载具 + 起点 + 终点 + 路线后，自动计算并展示：总距离、纯行进时间、休息次数与时长、总耗时、出发/到达时间（按当前地图粒度显示到 年/月/日/时/分）；支持**一键创建运输事件**挂到时间轴。

> 计算规则见 [数据模型规格 §10.1](数据模型规格_v0.1.md)；挂载见 [时间轴系统规格 §2.1](时间轴系统规格_v0.1.md)。

## 7. 呈现模式与视觉风格

### 7.1 呈现模式

地图不仅是编辑对象，也是展示对象。提供以下模式（存于地图 `presentation.default_mode`）：

| 模式 | 值 | 说明 | v0.1 |
|---|---|---|---|
| 编辑模式 | `edit` | 显示网格/坐标/图层控制/工具栏 | ✔ |
| 预览模式 | `preview` | 隐藏网格与工具，干净地图 | ✔ |
| 回放模式 | `replay` | 时间轴驱动的**只读**动态展示 | ✔（M6） |
| 演示模式 | `demo` | 全屏无 UI、带动画/事件弹窗/载具移动 | 设计预留，未实现 |
| 观察者视角 | `gm`/`player`/`faction` | 按视角显示不同图层（战争迷雾、未知区域） | 设计预留，未实现 |

> 编辑态与回放态的**可编辑性差异**（回放为只读）见 [界面与交互规格](界面与交互规格_v0.1.md) §2.5 / §3。

### 7.2 视觉风格

- **主题**（`presentation.theme`）：羊皮纸 `parchment`（默认）/ 写实 `realistic` / 简约 `minimal` / 暗黑 `dark` / 奇幻 `fantasy` / 科幻 `scifi`；v0.1 至少提供 `parchment`。
- **地形表现**：色板、纹理、高度阴影、等高线、河流动画、海岸线、植被点缀。
- **标记与图标**：城市/村庄/要塞/神庙/传送门；事件点/任务点/危险点；人物/载具/军队；路线/航线/商路。
- **势力与影响力**：势力颜色、疆界描边、影响力热力图、争议区斜纹、停战线虚线。

> 视觉风格属**渲染层**表现，不影响领域数据；主题图例与默认配色 `[待标定]`。

#### 7.2.1 内容美术风格（`presentation.art_style`，v0.1 增补）

## 8. 测量、信息面板与交互

### 8.1 测量工具

| 工具 | 输入 | 输出 | 单位 |
|---|---|---|---|
| **距离测量** | 鼠标拖拽多点折线 | 总长与每段距离 | `grid.distance_unit`（所在地图的物理单位） |
| **面积测量** | 多边形选区（与 §1.2 套索/方框复用） | 面积 | `distance_unit²` |
| **路径测量** | 起点 → 终点 + 路线类型 | 图上路径长 + 节点数 | 同距离 |
| **运输耗时测量** | 起点 + 终点 + 路线类型 + 载具 | 复用 §6.3 的运输时间计算 | 输出 `total_duration` + `arrive_time`（按当前地图粒度） |
| **事件时间测量** | 两个时间点（按时刻度上拖拽） | 两时刻间隔（年/月/日/时/分） | 按 `era` 与事件时间精度 |

- 所有测量**只读**，不落盘（属 `ui` 辅助层，见 [图层系统规格](图层系统规格_v0.1.md) §3）。
- 距离/面积内部先归一到 `base_unit` 再计算，避免多次换算（与 §1.4 一致）。
- 跨地图测量通过 `anchor` 映射到同图坐标后累加（见 [数据模型规格 §2.10](数据模型规格_v0.1.md)）。

### 8.2 信息面板

- **悬停**：显示地形、高度、归属。
- **点击**：显示对象详情（城市/建筑/人物/事件/载具/运输任务）。
- 事件点显示时间、人物、描述；人物显示当前位置与状态；载具显示速度、载人、任务。

### 8.3 基础操作

左键绘制、右键菜单、中键平移、滚轮缩放、框选/多选、复制/粘贴/删除、撤销/重做、对齐/吸附。

### 8.4 地图切换

世界地图点击城市 → 弹出卡片 → 进入城市地图；城市地图点击建筑 → 弹出卡片 → 进入室内地图；面包屑逐级返回；支持**多地图标签页**。

## 10. 编辑操作 → 数据写入对照
