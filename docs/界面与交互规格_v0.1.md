# 界面与交互规格 v0.1

> 定义主界面布局与核心交互流程。渲染实现技术中立（Canvas / WebGL 均适用），见 [总体设计 §3](总体设计_v0.1.md)。

---

## 1. 主界面布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏 Toolbar                                                          │
│  [时间轴滑块 ◀━━━●━━━▶]  [时间显示 创世历 1042年3月12日 14时]  [图层开关 ▾] │
├──────────────┬──────────────────────────────────────┬────────────────┤
│ 左侧面板      │                                      │ 右侧面板        │
│ Tools        │           地图画布 Canvas             │ Panels          │
│              │                                      │                 │
│ · 工具栏      │      （当前地图的编辑/查看视图）       │ · 人物列表       │
│ · 笔刷模式    │                                      │ · 事件列表       │
│ · 地形选择    │                                      │ · 选中对象信息    │
│ · 高度设置    │                                      │                 │
├──────────────┴──────────────────────────────────────┴────────────────┤
│ 状态栏：面包屑（世界 › 极光港 › 码头酒馆）｜当前地图 ｜ 比例尺 ｜ 当前时间粒度 ｜ 坐标 ｜ 提示 │
└──────────────────────────────────────────────────────────────────────┘
```

### 1.1 顶栏（时间轴 + 图层）

| 元素 | 功能 |
|---|---|
| **时间轴滑块** | 拖动改变当前时刻；地图随之更新（见 [时间轴系统规格 §3](时间轴系统规格_v0.1.md)） |
| **时间显示** | 按当前地图 `time.display_format` 格式化；切换地图时粒度随之改变 |
| **图层开关** | 展开图层面板：显示/隐藏、锁定、透明度、叠加顺序、时间有效性 |
| **呈现模式切换** | 编辑 / 预览 / 回放 三态切换（演示与观察者视角为设计预留，见 [地图编辑器规格 §7](地图编辑器规格_v0.1.md)） |
| **视图模式切换** | 2D / 2.5D / 3D（v0.1 仅 `2d`，见 [地图编辑器规格 §5](地图编辑器规格_v0.1.md)） |

### 1.2 左侧面板（工具）

| 分组 | 内容 |
|---|---|
| 工具栏 | 选择、笔刷、选区（方框/圆形/套索/魔术棒/填充）、道路、路线、放置（城市/建筑/载具）、测量 |
| 笔刷模式 | 圆形/方形/套索/魔术棒/沿路径/填充（见 [地图编辑器规格 §1.1](地图编辑器规格_v0.1.md)） |
| 地形选择 | 地形类型调色板（见 [数据模型规格 §3.1](数据模型规格_v0.1.md)） |
| 高度设置 | 笔刷高度值/增量、抬升/降低/平滑/平整、噪声/山脊/河流生成、等高线/色阶（见 [地图编辑器规格 §2.2](地图编辑器规格_v0.1.md)） |
| 测量工具 | 测距离/面积/路径/时间/运输耗时（见 [地图编辑器规格 §8.1](地图编辑器规格_v0.1.md)） |

### 1.3 中间（地图画布）

- 显示当前地图，支持平移、缩放（2.5D/3D 另支持旋转）、聚焦选区、全图适配、小地图导航。
- 顶部提供**多地图标签页**，可在世界/城市/室内地图间切换。
- 图层面板控制哪些图层参与渲染；编辑操作直接作用于画布。

### 1.4 右侧面板（数据）

| 面板 | 内容 |
|---|---|
| **人物列表** | 可搜索、可筛选（按势力/居住地/标签） |
| **事件列表** | 可搜索；点击定位到地图与时间轴 |
| **载具列表** | 可搜索、可筛选（按类型/势力/状态）；显示当前地图与坐标 |
| **运输任务列表** | 任务列表 + 状态（计划中/运输中/已到达/取消）+ 任务时间轴与中途事件 |
| **选中对象信息** | 显示当前选中对象（城市/建筑/人物/事件/载具/运输任务）的详情，可编辑 |

### 1.5 地图设置面板

每张地图有独立的**地图设置面板**，分五组（字段见 [数据模型规格 §2.2/§2.3/§2.7/§2.8/§2.10](数据模型规格_v0.1.md)）：

| 分组 | 设置项 |
|---|---|
| 网格与距离 | 网格宽/高、单格距离、距离单位、高度单位、坐标原点、显示网格、吸附网格、比例尺 |
| 时间设置 | 默认时间粒度、最小时间粒度、时间显示格式、事件排序单位、是否继承工程历法、是否允许模糊时间 |
| 运输与通行 | 是否允许飞行/水上/地下、道路层引用、航线/路线层引用、传送点列表 |
| 引用设置 | 父地图、子地图列表、城市入口坐标、建筑入口坐标、跨地图时间轴同步方式 |
| 坐标映射 | `anchor.parent_x/parent_y`、`scale`、`rotation`（见 [数据模型规格 §2.10](数据模型规格_v0.1.md)）；`extent` 为派生值，仅供显示与校验对比 |
| 呈现 | `default_mode`（edit/preview/replay）、`view_mode`（v0.1 仅 `2d`）、`theme`、`observer`（预留）、`show_scale_bar`、`show_coordinates`、`show_minimap` |

- 进入子地图时，网格、比例尺、距离单位、吸附与时间轴粒度**自动切换**为该地图设置；返回父地图时切回。
- `anchor` 错位 / 越界时，地图设置面板**显式告警**（与校验器一致），并提示重新设置。

### 1.6 载具登记面板

新建/编辑载具（字段见 [数据模型规格 §8](数据模型规格_v0.1.md)）：

| 步骤 | 内容 |
|---|---|
| 选择类型 | 大类（陆行/飞行/水上/地下/传送/特殊）+ 自由子类型 |
| 速度 | 基础速度、速度单位、最大/巡航速度、加速时间、地形系数 |
| 运输能力 | 最大/舒适载人数、最大载货量、载货单位、最大载重、特殊限制、最低驾驶/护卫人数 |
| 休息规则 | 连续行进上限、单次休息时长、每日最大行进、每日强制休息、疲劳惩罚、夜间是否行进、地形/天气对休息的影响 |
| 指派 | 指定所有者（势力/人物）、驾驶者、乘员 |
| 保存 | 写入 `vehicles/` 并加入载具列表 |

## 2. 核心交互流程

### 2.1 世界地图 → 城市地图 下钻

```
世界地图
  └─ 点击城市 → 弹出【基础信息卡】（名称/人口/势力/备注）
        └─ 点击【进入编辑】→ 切换到城市地图
              └─ 点击特殊建筑 → 若存在 interior_ref → 【进入内部】→ 室内图
```

- 面包屑记录路径，可逐级返回。
- 城市条目 `map_ref` 为空时，「进入编辑」变为「创建城市地图」。

### 2.2 城市地图放置建筑 → 生成居民 → 编辑居民

```
城市地图
  └─ 放置建筑（选择类型）→ 写入 building_refs
        └─ 触发【居民生成】→ 按建筑类型/人口密度/财富/势力生成居民名单
              └─ 居民写入 characters/，可【逐个编辑】走人物登记流程
```

### 2.3 事件登记（含地图拾取）

```
打开事件登记面板
  ├─ 选择时间（时间轴取点 / 输入；可只精确到年/月，标记模糊时间）
  ├─ 选择地点：在地图上【点击拾取坐标】，或从列表选城市/建筑/区域/地下层
  ├─ 添加参与者 / 目击者 / 发起者（从人物列表选）
  ├─ 填写描述、结果、影响范围
  ├─ 关联前置/后续事件
  └─ 保存 → 地图事件层出现标记 + 时间轴出现标记
```

### 2.4 人物登记与事件引用

```
新建人物 → 填基础信息 → 选性格标签 → 定义/套用自定义属性模板
        → 设置关系（家族/盟友/敌人/师徒/恋人）
        → 关联居住地、所属势力
        → 保存 → 可在事件登记中被引用为参与者
```

### 2.5 图层与时间轴联动

- 图层可独立开关；锁定后不可编辑但仍渲染。
- 拖动时间轴 → 落在有效区间外的图层自动隐藏；疆界、事件点、城市归属随之变化。
- 回放态为**只读**；若要修改，须显式「在此刻登记新事件」。

### 2.6 运输任务登记与时间预估

```
时间预估面板
  ├─ 选择载具（速度/载力/休息规则）
  ├─ 选择起点、终点（地图拾取或多粒度地点选择）
  ├─ 选择/绘制路线（陆上沿路 / 飞行直线 / 水上沿航线 / 地下 / 传送）
  ├─ 自动计算距离（沿道路/航线总长、飞行直线、跨地图归一 base_unit）
  ├─ 自动计算休息（连续行进上限、每日最大行进、强制休息、夜间规则）
  ├─ 显示总耗时与出发/到达时间（精确到 年/月/日/时/分）
  └─ 一键创建运输事件（is_transport）→ 挂到时间轴 + 生成中途事件
```

- 路线绘制工具与路线类型对照见 [地图编辑器规格 §2.5](地图编辑器规格_v0.1.md)。
- 运输任务列表管理任务状态、时间轴与中途事件，并展示关联人物/势力/载具。
- 时间计算为**纯逻辑**（领域层可单测），界面仅做参数收集与结果展示（见 [数据模型规格 §10.1](数据模型规格_v0.1.md)）。

## 3. 交互一致性约定

| 约定 | 说明 |
|---|---|
| **选区与笔刷共用撤销栈** | 所有编辑操作可撤销/重做（非破坏编辑原则） |
| **引用选择器统一** | 选人物/事件/建筑一律用带搜索的选择器，禁止手输 ID |
| **断链显式提示** | 引用失效时展示「缺失」并给出修复入口，不静默 |
| **长任务有进度** | 居民生成、疆界贴合、导入导出等显示进度，可取消 |
| **时间态可辨识** | 回放态（非最新时刻）必须视觉上可区分，防止误以为在改当前状态 |
| **呈现模式可辨识** | 编辑/预览/回放可切换且当前态可见；预览隐藏网格与工具，回放为**只读**（见 [地图编辑器规格 §7](地图编辑器规格_v0.1.md)） |
| **坐标系一致** | 跨地图引用统一用「世界坐标 + 地图路径」；进入子地图自动切换为子地图坐标（见 [地图编辑器规格 §5.3](地图编辑器规格_v0.1.md)） |

## 6. 状态管理：UI 状态 vs 领域数据（v0.1 补充）

> 本节为 P0 收敛后追加的纪律条款，与 [技术基调确认_v0.1.md](技术基调确认_v0.1.md) §7 对齐。

v0.1 推荐前端状态库为 **Zustand / Pinia**（或同等的轻量 store）。状态严格分层：

| 类别 | 承载内容 | 落盘 | 备注 |
|---|---|---|---|
| **领域数据** | 工程 / 地图 / 地形 / 图层 / 人物 / 事件 / 时间轴 / 载具 / 路线 / 运输任务 | ✔ YAML + 二进制分块 | 由 [数据模型规格](数据模型规格_v0.1.md) 定义；UI 不得持有与之等价的副本超过**当前打开的工程实例**生命周期 |
| **UI 状态** | 当前工具、笔刷参数、选区、图层开关、缩放 / 平移 / 视口、当前时刻、对齐 / 吸附开关、面板布局、拖拽预览 | ✘（仅内存，可选择性入 `settings`） | 由前端状态库直接持有；切换 / 关闭工程时清空 |
| **渲染缓存** | PixiJS 对象、`RenderTexture`、脏区标记、空间索引（quadtree / R 树） | ✘ | 仅在渲染层持有；与 UI 状态分层，不得混进状态库 |
| **撤销 / 重做栈** | 编辑操作（命令对象） | ✔（可选入「快照」） | 命令对象序列化形式须能落盘 / 错误跨域（见 [地图编辑器规格 §1.3](地图编辑器规格_v0.1.md)） |

**纪律**：

- **数据契约中立**。UI 状态库**只承载** UI 状态；**不得**把 PixiJS 对象、Tauri 命令、序列化缓冲直接混入领域数据 store。
- **领域数据 ↔ UI 状态单向**：编辑操作 = 领域数据写入 + 同步发出「状态变化事件」→ UI 状态库订阅并更新（撤销 / 重做、笔刷预览等）；UI 状态变更**不得绕过领域层直接写文件**。
- **渲染缓存不进 store**。空间索引、纹理缓存、脏区标记属于渲染层内部对象，由渲染层生命周期管理。
- **多地图标签页**：每张打开的地图在领域数据 store 中有独立实例；UI 状态（视口 / 工具 / 选区）按地图键隔离，避免切换时回显。
- **关闭工程**：UI 状态、渲染缓存随会话释放；领域数据按用户保存决策落盘。

> 该分层与 [总体设计 §3](总体设计_v0.1.md) 的「依赖方向自下而上单向」原则一致；落地时建议在 store 入口强制分层（领域 store 不引入渲染 / 框架类型），防止后续误用。
