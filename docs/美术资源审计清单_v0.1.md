## 3. 失败处理协议

按 [CCGS /asset-audit](https://github.com/Donchitos/Claude-Code-Game-Studios) 的合规语义，本审计结论分四档：

| 结论 | 触发条件 | 处置 |
|---|---|---|
| **NON-COMPLIANT** | 任何 #1–#5 / #9 / #13 失败，或 #6 / #10 / #11 部分失败 | 阻塞合并，必须修复 |
| **WARNINGS** | 仅 #7 / #8 / #12 部分失败（少量文件遗漏） | 不阻塞，须在 7 日内修复 |
| **NOT ASSESSED** | 输入缺失（无资产、无 styles.yaml 等） | 不阻塞，须先建立输入后再审 |
| **COMPLIANT** | 13/13 全 PASS | 通过审计 |
