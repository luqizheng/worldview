# 美术资源规范 v0.1

> World View 项目美术资源的**目录、命名、生成、导入**规范。
>
> 适用于：v0.1 阶段（Godot 4.7.2 mono / C#），单地图样例工程（`examples/sample_world/`）。
>
> 真源：本文件 + `assets/textures/tiles/styles.yaml` + `assets/palettes/parchment_palette.yaml`。
>
> 数据契约字段真源：`docs/数据模型规格_v0.1.md §2.4`（颜色）、`docs/图层系统规格_v0.1.md §2.3/2.5`（Marker 图标引用）。

## 1. 设计原则

| 原则 | 含义 | 本规范落地 |
|------|------|----------|
| 单机 | 资源必须随工程可拷走 | 全部 PNG/YAML/JSON 入版本库；`.godot/` 与 `.import` 不入库 |
| 目录即工程 | 不建二进制 manifest | `assets/` 树形目录 + 每个子目录 `index.yaml` |
| YAML 为主格式 | 元数据禁止二进制 | 调色板用 YAML；JSON 仅用于 PixiJS 兼容的 atlas 帧元数据 |
| 像素风一致 | 与现有 `examples/sample_world/assets/textures/tiles/` 风格统一 | 64×64 主瓦片 / 16×16 marker icon / 1px inner padding |
| Domain 层唯一真源 | 颜色 hex 不在资源里另立 | `parchment_palette.yaml` 的 `terrain.*` 与 `Domain.TerrainDefaults.ColorHex` 一一对应 |

### 1.1 风格定位

- **目标受众**：TRPG 主持人 / 小说作者 / 世界观构建者——气质偏「羊皮卷 + 工坊」，**不**做软件渲染写实风（3D 写实 / CG 电影质感）、不做赛博朋克霓虹、不做软件层 3D 渲染
- **核心隐喻**：羊皮纸 + 像素风 = 「手工绘制的世界」——视觉强度低、信息密度高、长时间编辑不疲劳
- **两轴分层**（v0.1）：
  - **UI 主题轴** = `Map.presentation.theme`（parchment / realistic / minimal / dark / fantasy / scifi）——管控件 / 主题色 / 字体 / 图标,见 [数据模型规格 §2.8](数据模型规格_v0.1.md)
  - **内容美术轴** = `Map.presentation.art_style`（jrpg / western_fantasy / ink_wash）——管地图内容的建筑 / 地形 / 地标 / 室内陈设渲染
  - 二者**正交**,可任意组合(如「parchment UI + ink_wash 内容」)
- **默认内容风格 ID**：`jrpg`（已在 `assets/textures/tiles/styles.yaml:2` 登记,已实装）
- **占位内容风格 ID**：`western_fantasy` / `ink_wash`（v0.1 **仅画像 + YAML 占位**,资源未交付时通过既有 fallback 退回 `jrpg` + 纯色块；资源、拒绝清单、PALETTE 色值标定列入 T-ART-7 / T-ART-8,推迟到独立工单）
- **变体预留**：`_fallback_solid_color`（无资产时的纯色兜底）

### 1.2 拒绝清单

> 任何美术资源 / Theme / UI 控件若触犯下列任一条，须改回或显式标注 `[已知违反：原因]`，不得静默放过。

| # | 拒绝项 | 理由 |
|---|---|---|
| 1 | 渐变（除单像素抗锯齿过渡外） | 像素风一致性 |
| 2 | drop-shadow blur > 2px | 风格统一 + 性能 |
| 3 | 字号 < 10px（accessibility floor） | WCAG / 中文可读性 |
| 4 | 红色滥用（仅作强调/危险态，正文用深褐） | 与羊皮底 `#f4f0e4` 对比过强，长时间阅读疲劳 |
| 5 | 单一图标尺寸 > 32px（在画布上） | 破坏「地图优先」视觉层级 |
| 6 | mipmap 自动生成 | `process/mipmaps/generate = false`（§5 硬约束） |
| 7 | 不写 `.png.import` 直接放 PNG | Godot 4 找不到 `.import` 会自动重建，uid 漂移 |
| 8 | 大于 1KB 的元数据落二进制 | 违反「YAML 为主格式」（AGENTS.md §2 原则 3） |
| 9 | 同一资产出现两个主题色版本 | 单一主题变量驱动，色值只允许来自对应风格 `<id>_palette.yaml` |
| 10 | `BottomPalette` / `DockLayout` / `ProjectChrome` 控件超过 3 层 Container 嵌套 | UI 重设计 W1–W4 已收敛嵌套深度 |
| 11 | 内容色饱和度 > 70%（HSL） | 与羊皮底 `#f4f0e4` 对比过强，破坏长时间阅读（JRPG 内容美术，2026-10-09 增补） |
| 12 | 建筑 sprite 超过 32×32 像素 | 破坏「图标 ≤ 32px」纪律（JRPG 内容美术，2026-10-09 增补） |
| 13 | 地形纹理超过 4 色（纯色 base + 1 mid + 1 dark + 1 accent = 4 封顶） | 像素风 + 调色板纪律（JRPG 内容美术，2026-10-09 增补） |
| 14 | 室内陈设超过 3 层 Container 嵌套 | 与 §1.2#10 同源（JRPG 内容美术，2026-10-09 增补） |

> 上述拒绝项 #1–#10 是**软件渲染 + UI 层**约束；**内容美术层**（`art_style`）的色值纪律由各风格的 `<id>_palette.yaml` 定义，`western_fantasy` / `ink_wash` 的拒绝清单在 T-ART-7 / T-ART-8 工单落地；`jrpg` 内容美术专属约束见 #11–#14（本轮新增）。

> 方法论来源：[美术指导借鉴方案 v0.1 §3](美术指导借鉴方案_v0.1.md)。CCGS 风格的视觉总纲是「规则就是设计」——拒绝清单与设计原则同等重要。

## 2. 目录布局

```
assets/
├── icons/                    # marker icon atlas（marker / event / faction）
│   ├── icons_atlas.png       # 120×18 = (16+1)×7 + 1
│   ├── icons_atlas.json      # PixiJS 风格帧元数据
│   ├── icons_atlas.png.import
│   ├── index.yaml            # 帧名清单 + 数据契约引用
│   └── _preview.png          # 4× 放大审阅图（不入运行时）
│
├── palettes/                 # 调色板（YAML 唯一真源）
│   └── parchment_palette.yaml
│
├── textures/tiles/           # 主瓦片根目录（与 styles.yaml 同目录）
│   ├── styles.yaml           # 风格清单，jrpg 为默认
│   ├── terrain_atlas.png     # 64×64 × 11 帧（沿用 examples）
│   ├── road_atlas.png        # 64×64 × 11 帧
│   ├── river_atlas.png       # 64×64 × 8 帧
│   ├── border_atlas.png      # 64×64 × 4 帧
│   ├── *.png.import
│   └── tileset.tres          # 命名固定（TileSetLoader 约定）
│
└── themes/                   # UI 主题
    └── parchment_theme.tres

styles/
├── jrpg/                   # 默认内容美术风格（已实装）
│   ├── tileset.tres        # 同名约定见 §2 关键约束 1
│   ├── terrain_atlas.png + .import
│   ├── road_atlas.png + .import
│   ├── river_atlas.png + .import
│   ├── border_atlas.png + .import
│   └── index.yaml
├── western_fantasy/        # v0.1 占位；目录到达前 styles.yaml 的 path: _placeholder 触发 fallback
├── ink_wash/               # 同上
└── _fallback_solid_color/  # 纯色兜底（无资产时退化）
```

**关键约束**：

1. `tileset.tres` 必须位于 `res://assets/textures/tiles/<style_id>/tileset.tres`（与 `styles.yaml` 中该风格 `path` 指向的目录同层），文件名固定为 `tileset.tres`（`scripts/Editor/TileSetLoader.cs:33` 硬编码）。
2. 任何在 `styles.yaml` 中声明的 `path: <dir>` 必须在 `res://assets/textures/tiles/<style_id>/` 下能找到 `tileset.tres`；找不到时 `TileSetLoader` 降级到 `TerrainTileSetFactory.Build()` 的纯色兜底（见 `TileSetLoader.cs:104`）。
3. `.png.import` 必须与 `.png` 同目录（Godot 4 硬性约束）。
4. PNG 内容跨 `res://` 引用合法，但 `.import` 文件必须随 PNG 走（Godot 4 找不到 `.import` 会自动重建）。
5. **内容美术风格目录布局**：每套风格一个子目录 `<style_id>/`，子目录内必须有 `tileset.tres` 与 `index.yaml`；Palette 走 `assets/palettes/<style_id>_palette.yaml`（不放在 styles/ 下；Palette 是调色板真源，与 atlas 解耦）。

## 3. 命名约定

| 资源 | 命名 | 示例 |
|------|------|------|
| Marker icon 帧 | `<category>_<variant>` | `settlement_village`, `event_point`, `faction_dot` |
| 地形帧 | 与 `TerrainType` 枚举小写同名 | `plain`, `mountain`, `forest`, `coast` |
| 道路帧 | `<shape>` 或 `<shape>_<modifier>` | `h`, `v`, `bend_tl`, `cross`, `endcap` |
| 河流帧 | `river_<shape>` | `river_h`, `river_bend_tr` |
| 边界帧 | `border_<style>` | `border_solid`, `border_dashed` |
| Theme 资源 | `<skin>_theme.tres` | `parchment_theme.tres` |
| Palette 文件 | `<style_id>_palette.yaml` | `parchment_palette.yaml`（UI 主题）；`jrpg_palette.yaml` / `western_fantasy_palette.yaml` / `ink_wash_palette.yaml`（内容美术） |
| 风格目录 | `assets/textures/tiles/<style_id>/` | `jrpg/`（已实装）；`western_fantasy/` / `ink_wash/`（v0.1 占位） |
| TileSet 资源 | `tileset.tres`（固定） | `res://assets/textures/tiles/<style_id>/tileset.tres` |

## 4. 几何与颜色

### 4.1 主瓦片（terrain / road / river / border）
- **cell 像素**：`64×64`
- **inner padding**：`1px`（与 `separation: 1` 配合，避免纹理过滤时跨帧渗色）
- **TileSet.TileSize = (64, 64)**，`TextureRegionSize = (64, 64)`
- **生成器**：`_tools/make_tiles.py`（64×64 像素、2px 描边、8×8 dot stipple 同底纹）
- **调色板**：见 `_tools/make_tiles.py:54-77` 的 `TERRAIN_PALETTE`（与 `parchment_palette.yaml:terrain.*` 同色系但不完全相同——PNG 用 4 色 base/mid/dark/accent，YAML 用单一 hex 显示色）

### 4.2 Marker icon atlas
- **cell 像素**：`16×16`
- **inner padding**：`1px`
- **总宽**：`120 px`（= (16+1) × 7 + 1），**总高**：`18 px`（= 16 + 2×1）
- **生成器**：`_tools/make_marker_icons.py`
- **调色板**：脚本内 `PALETTE` 字典（11 个字符：`.` 透明、`k` 深褐轮廓、`K` 暖褐、`t` tan、`T` 沙色、`r` 朱红、`y` 暖黄、`c` 浅蓝、`g` 苔绿、`s` 银灰、`w` 羊皮底）
- **帧名**：与 `Marker.icon` 字段（数据模型 §2.4）一一对应

### 4.3 调色板
- 字段：`#RRGGBB` 或 `#RRGGBBAA`（缺省 AA=FF）
- `terrain.*` 必须与 `Domain.TerrainDefaults.ColorHex` 一一对应（脚本校验见 TODO 23+）
- `marker.*` 是 marker icon 的语义主色，**不强制与 `PALETTE` 字符一致**——脚本生成时人工调色
- **每套内容美术风格独立 Palette**：`<style_id>_palette.yaml`；骨架字段名（`terrain.*` / `marker.*` / `ui.*` / `accent.*`）保持一致，色值按各风格定调；v0.1 占位文件 `western_fantasy_palette.yaml` / `ink_wash_palette.yaml` 色值全 `[待标定]`

### 4.4 UI 主题（parchment）
- 主色：羊皮底 `#e8d4a2`、暖褐描边 `#5c4326`、朱红强调 `#8b3a2e`、深褐文本 `#2a1f10`
- 与 `scripts/Ui/Theme/Dark.tres` 互补——Dark 是暗夜模式，Parchment 是默认亮色模式（**2026-10-09 删除**：项目已收敛为单一 Parchment 主题，Dark 下线）
- 覆盖 Dark 的关键控件：Button / Label / Panel / PanelContainer / ItemList / LineEdit / TextEdit / ScrollContainer / HSeparator / VSeparator

### 4.5 基础 UI 组件视觉契约（v0.1 增补，JRPG）

> **背景**：本节为 JRPG 软件 UI 美术风格定调的视觉契约真源。本轮已通过 `dsh-image-gen` 出 7 张审稿参考图（清单见 §4.7），**审稿通过**后此表作为代码层 `JrpgButton` / `JrpgList` / `JrpgTextBox` / `JrpgPanel` / `JrpgCheckBox` / `JrpgDropDown` 等组件程序化绘制的依据；`assets/` 下不落任何 UI 主题 PNG（UI 走 `_draw()` 或 9-slice sprite，**不**走 `dsh-image-gen`）。
>
> **纪律继承**：所有约束同时遵守 [§1.2 拒绝清单](#12-拒绝清单)（渐变 / drop-shadow blur > 2px / 字号 < 10px / 红色滥用 / 图标 > 32px）；本节不重复列出，只追加 JRPG 专属项。

#### 4.5.3 通用字体与排版

| 项 | 取值 |
|---|---|
| 主字体 | 衬线(`SerifFallback` / 系统衬线回退);JRPG 风走"羊皮卷工坊"气质,不要无衬线 |
| 正文字号 | **14px**(≥ 拒绝清单#3 底线 10px,本规范自提到 14px 保障长时间阅读) |
| 标题字号 | 14–18px 粗体 |
| 行高 | 22px(对应 14px 字号 × 1.57) |
| 段间距 | 8px |
| 字距 | 默认,标题可 +0.5px(增加"印章感") |

#### 4.5.4 阴影与边框规则

| 项 | 取值 |
|---|---|
| drop-shadow blur | **≤ 2px**(拒绝清单#2);Panel 例外可放宽到 ≤ 2px 但偏移 ≤ 1px |
| 描边宽度 | **2px 统一**,不为每组件单独设色;焦点态金黄替换焦褐,**不**叠加 |
| 圆角 | 0–2px;**不要** Material Design 的大圆角;**不要**椭圆 |
| 渐变 | 禁(拒绝清单#1,单像素抗锯齿过渡除外) |

#### 4.5.5 拒绝清单（UI 层，补充）

| # | 拒绝项 | 理由 |
|---|---|---|
| 11 | 按钮 / 输入框圆角 > 4px | 破坏像素风一致性 |
| 12 | 焦点态同时叠加 金黄描边 + 外发光 | 描边替换已足够视觉提示,叠加破坏 §4.5.4 描边宽度统一 |
| 13 | DropDown 展开列表未沿用 List 组件契约(独立一套配色 / 圆角 / 行高) | 视觉一致性 |
| 14 | 在 14px 字号以下渲染中文/日文 | §1.2 拒绝清单#3 的字面下限;JRPG 风不破 |

## 5. PNG 导入约定

`.png.import` 关键字段（沿用 `examples/sample_world/.../*.png.import`）：

| 字段 | 取值 | 说明 |
|------|------|------|
| `compress/mode` | `0` | 无损（VRAM 压缩关闭） |
| `mipmaps/generate` | `false` | 像素艺术不用 mipmap |
| `process/fix_alpha_border` | `true` | 防止半透明边缘发黑 |
| `process/premult_alpha` | `false` | 与 `markers.png` 现有 PNG 保持一致 |
| `detect_3d/compress_to` | `1` | 2D 纹理 |

新加 PNG 必须**手写** `.png.import`（与现有 atlases 同形），否则 Godot 首次打开会重建——但 uid 会变（`uid://b1...000` 占位会被替换为真值）。

### 6.2 `_tools/make_marker_icons.py`（新增）

- 1 个 atlas：7 帧（village / town / capital / ruins / event_point / portal / faction_dot）
- 调色板见脚本内 `PALETTE`
- 同时输出 `_preview.png`（每帧 4× 放大，便于审阅）

### 6.3 运行
```bash
python _tools/make_tiles.py          # 重生成 examples/ 下 4 个 atlas
python _tools/make_marker_icons.py   # 重生成 assets/icons/icons_atlas.png
```

两个脚本均**幂等**：同输入产生字节相同的 PNG（marker icon 的 `deterministic?` 取决于字符矩阵——目前是常量字面量，因此幂等）。
